# Fundación Peluditos con Futuro 🐾

Este repositorio contiene el código desarrollado como voluntariado para la fundación **Peluditos con Futuro**, una organización sin fines de lucro dedicada al rescate, cuidado, rehabilitación y adopción de animales en situación de calle.

El objetivo principal de este proyecto es proporcionar una plataforma web funcional, accesible y visualmente atractiva que permita a los usuarios conocer la labor de la fundación, informarse sobre cada uno de los animales disponibles para adopción, aprender sobre el cuidado responsable de mascotas y facilitar los procesos de colaboración y adopción.

## Estructura del Proyecto

El proyecto se encuentra organizado en las siguientes secciones clave dentro del sitio web:

### 📌 Presentación de la Fundación
Sección donde se introduce la misión, visión y valores de la fundación **Peluditos con Futuro**, junto con una descripción general de sus objetivos y acciones para mejorar la calidad de vida de los animales en situación de abandono.

### 🐶 Galería de Animales Rescatados
Muestra una lista actualizada de todos los animales actualmente bajo el cuidado de la fundación. Cada animal cuenta con:

- 📷 Fotografía representativa
- 📄 Nombre
- 🗓 Edad aproximada
- ⚥ Sexo
- 📝 Descripción de su historia o personalidad

Esta sección tiene como objetivo facilitar el proceso de adopción al permitir que las personas conozcan mejor a los animales.

### 📚 Blog de Cuidados
Una sección de contenido educativo sobre:

- Consejos de cuidado responsable de mascotas
- Alimentación adecuada
- Salud y vacunación
- Esterilización
- Adaptación de animales rescatados
- Recomendaciones para adopción segura

Este blog está diseñado para sensibilizar y educar a los visitantes, promoviendo el bienestar animal.

### 🧑‍🤝‍🧑 Equipo de Trabajo
Aquí se presenta al equipo humano que forma parte de **Peluditos con Futuro**, incluyendo fundadores, voluntarios, veterinarios colaboradores y cuidadores. Se detalla su rol, experiencia y motivación por ayudar a los animales.

### 💛 ¿Cómo Apoyar?
Se ofrece información clara sobre las distintas formas en que las personas pueden colaborar con la fundación, entre ellas:

- Donaciones económicas
- Donaciones en especie (alimento, medicinas, insumos veterinarios)
- Voluntariado
- Hogares temporales
- Difusión en redes sociales

Cada opción incluye datos de contacto, métodos de transferencia y formularios si aplica.

### 📝 Proceso de Adopción
En esta sección se describe detalladamente el procedimiento necesario para adoptar un animal, incluyendo:

- Requisitos para adoptantes
- Evaluación y formulario de adopción
- Documentación necesaria
- Seguimiento post-adopción

También se puede acceder y descargar los formularios y documentos oficiales requeridos para iniciar el proceso.

## Estructura del Repositorio

- 📁 `Tienda`: Carpeta principal que contiene todo el código fuente del sitio web (HTML, CSS, JS, PHP).
- 🗃️ `db_peluditos`: Base de datos del proyecto, donde se almacenan los registros de animales, usuarios y formularios de adopción.
